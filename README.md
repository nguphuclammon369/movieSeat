# Movie Seat Selection - Redux Action Creator

Bản này được thiết kế bám sát bố cục demo Movie Seat Selection của W3Layouts:

- Movie Seat Selection
- fill the required details below and select your seats
- Name
- Number of Seats
- Start Selecting
- Selected Seat / Reserved Seat / Empty Seat
- Sơ đồ A-J, 1-12
- Screen this way
- Confirm Selection
- Bảng Name / Number of Seats / Seats / Total

## Công nghệ
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Redux
- Action Creator

## Chạy
Mở thư mục bằng VS Code và chạy `index.html` với Live Server.

## Lưu ý
Redux và Google Fonts được tải qua CDN nên cần Internet khi chạy.
